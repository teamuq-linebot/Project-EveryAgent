# Evolution Agent — Org

## Belongs To
Agent Ops Team → `agents/agent-ops/manager/`

## Hierarchy
```
Agent Ops Manager
  ├─ Agent Builder
  ├─ Governance
  └─ Evolution  ←── THIS AGENT
```

## When to Pick
- 需要分析 agent 系統的效能趨勢
- 需要搜尋外部最新 agent 實踐
- 需要以組織學理論提出改善方案

## When NOT to Pick
- 直接修改 agent 檔案 → Agent Builder
- 審查 agent 變更 → Governance
- 寫應用程式碼 → SW Team
