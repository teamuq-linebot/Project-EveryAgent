# Evolution Protocol

Manager can evolve the agent system when existing agents can't handle a task. Two operations: **create** new agent or **enhance** existing agent.

Detail files:
- [Classification Principles](../agent-ops/evolution/classification-principles.md) — rules that all agents must follow
- [Create Agent](../agent-ops/evolution/create-agent.md) — how to add a new agent
- [Enhance Agent](../agent-ops/evolution/enhance-agent.md) — how to upgrade an existing agent
- [Decision Guide](../agent-ops/evolution/decision-guide.md) — create vs. enhance vs. reject
